# Selected styles

| Style | Design | Suitable use | Limits |
|---|---|---|---|
| d1 / Marginalia | Ivory, oxblood, book serif, wide annotation rail | Close reading, grammar explanations, teacher commentary | Long marginal notes need space checks |
| d2 / Grid | Cobalt and yellow, numbered index zone, strict grid | Structured workbooks and scan-friendly practice | OFL candidate substitutes Inter and Noto Serif SC; Chinese becomes serif |
| d3 / Index Cards | Color tabs, offset cards, friendly badges | Younger learners, vocabulary and scaffolded practice | OFL candidate keeps cards but loses original rounded Latin/Chinese lettering |

Choose D1, D2 or D3 for the current lesson. D2/D3 have an OFL font option and a system-font option with visible typography differences; the caller must select the font mode. Preserve any accepted earlier edition when trying an alternative.

Seven specimen roles: cover, words/sound, grammar, reading, cloze, writing, teacher-reading. These are not seven proven document families. Flashcards, listening sheets, phonics, slides and parent reports have no validated specimen here. The teacher-reading page is not a full teacher book.
